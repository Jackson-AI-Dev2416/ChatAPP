# TS3 Messenger — 보안

## 채팅 메시지 (사내 서버 신뢰 모델)

1. 메시지 `body`는 **평문**으로 서버 DB에 저장됩니다. 전송은 **HTTPS/WSS(TLS)** 로 보호합니다.
2. 총관리자·권한 있는 관리 API(`/api/v1/admin/chat/*`)에서 **내용 열람·감독**이 가능합니다.
3. 직원 메신저는 어떤 PC에서 로그인해도 동일한 대화 이력을 조회합니다.
4. (레거시) 예전 빌드가 저장한 `E1:` 클라이언트 암호문은 서버에서 복구할 수 없습니다.
5. 주소록 표시를 위해 클라이언트는 여전히 P-256 **공개키**를 등록할 수 있습니다(`PUT .../public-key`). 개인키는 **DPAPI** 로컬 저장(파일 전송·향후 기능용).

## 전송 계층

- REST·WebSocket은 **TLS**만 사용합니다.
- WebSocket 연결 시 `X-TS3-Client: TS3-Messenger` 헤더로 데스크톱 클라이언트를 식별합니다 (`chat_messenger_ws_allow_no_origin`).

## 파일

- 파일 바이트는 **암호화하지 않습니다**.
- 메타데이터만 서버 DB에 저장됩니다.
- 실제 전송은 수락 후 **LAN TCP** (WebSocket `file_punch`로 주소·포트 신호).

## 운영 주의

- 외부(인증·사내망 없음)는 TLS·세션 없이 내용에 접근할 수 없습니다.
- 세션 쿠키는 HttpOnly; CSRF 토큰은 모든 변경 API에 필요합니다.
